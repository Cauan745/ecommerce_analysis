# Análise de logística e satisfação

Aplicação em Streamlit para analisar pedidos da Olist. O projeto avalia atrasos nas entregas, diferenças entre estados e a relação entre o prazo de entrega e a nota dos clientes.

A visualização final dos resultados está disponível no [arquivo PDF](trabalho_final_cauan.pdf).

## Como executar

1. Instale as dependências com pip install -r requirements.txt.
2. Coloque os arquivos CSV na pasta dataset.
3. Inicie a aplicação com make dev.

Arquivos necessários:

- olist_customers_dataset.csv
- olist_orders_dataset.csv
- olist_order_reviews_dataset.csv

Os dados estão disponíveis no Brazilian E-Commerce Public Dataset by Olist, no Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
